# 실습 2 — 조직 데이터 고치기

**[English](README.md) | 한국어** · 강의: [05 에이전트 측정하기](https://github.com/ma-pmo/ma-pmo-ext/blob/main/docs/learn/05-measuring-agents.ko.md)

어느 PMO가 포트폴리오를 평가 양식으로 내보냈는데 실수가 섞여 있습니다. 망가진 데이터로 평가하면
그럴듯해 보이지만 의미 없는 숫자가 나옵니다. 그래서 하네스는 검사를 통과하기 전에는 평가를
돌리지 않습니다. 할 일은 **데이터를 버리지 않고** 검사를 통과시키는 것입니다.

**익히는 것:** 검사기 메시지 읽기, 원본에서 데이터 고치기, 정답 레이블이 H3(리스크 탐지) 같은
지표의 의미를 좌우하는 이유.

## 파일

- `data/*.csv`, `data/baselines.json` — 내보낸 데이터(`ma-pmo template data`와 같은 형식).

## 단계

1. 검사기를 실행하고 메시지를 모두 읽습니다.
   ```bash
   ma-pmo template validate learn/lab2/data
   ```
2. CSV 파일에서 오류를 하나씩 고칩니다(엑셀이나 텍스트 편집기 아무거나). 오류는 7개입니다.
   있을 수 없는 날짜, 100을 넘는 진척률, 중복된 태스크 id, 의존 관계 순환, 없는 태스크에 대한
   의존, 주당 168시간을 넘는 가용 시간, 허용 목록에 없는 리스크 심각도.
3. 행을 지우지 말고 고치세요. 중복된 `T-102` 행은 사실 `T-103`(WBS 1.3, T-102 다음)입니다.
   `T-320`은 오타이고, ACME-2는 `T-201`로 시작합니다.
4. 검사를 통과하면 별도 데이터베이스에서 평가해 봅니다.
   ```bash
   ma-pmo eval --data learn/lab2/data
   ```
