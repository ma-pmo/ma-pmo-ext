# 실습 3 — 제거 실험(ablation) 설계하기

**[English](README.md) | 한국어** · 강의: [06 실험과 테스트](https://github.com/ma-pmo/ma-pmo-ext/blob/main/docs/learn/06-experiments.ko.md)

가설 H4는 지식 에이전트(A7)가 과거 교훈을 실행에 끌어와 판단을 개선한다고 말합니다. **제거 실험
(ablation)**은 이 주장을 정면으로 시험합니다. 같은 시나리오를 A7이 있을 때와 없을 때 돌리고 결과를
비교합니다.

**익히는 것:** 가설을 실행 가능한 실험으로 바꾸기, 효과가 드러날 수 있는 시나리오 고르기, 실험을
작고 재현 가능하게 유지하기.

## 파일

- `experiments/h4_knowledge.py` — 직접 작성할 실험 파일.

## 단계

1. 시나리오와 각 시나리오가 쓰는 에이전트를 확인합니다.
   ```bash
   ma-pmo learn scenarios
   ```
2. **A7을 호출하는 시나리오를 2~5개** 고릅니다. A7을 쓰지도 않는 시나리오에서 A7을 빼면 아무것도
   바뀌지 않고 결과만 희석됩니다.
3. `.ablate("A7")`와 `.repeat(n)`(n은 1~3)을 추가합니다. 오프라인 실행은 결정론적이라 반복을 늘려도
   시간만 늘고 정보는 늘지 않습니다.
4. `TODO` 설명을 실험이 무엇을 측정하는지 한 문장으로 바꿉니다.
5. 다른 하네스 실험처럼 실행해 봅니다(`ma-pmo init-db`를 먼저 실행한 상태여야 합니다).
   ```bash
   MA_PMO_EXPERIMENTS_DIR=learn/lab3/experiments ma-pmo harness h4_knowledge
   ```

## 채점

```bash
ma-pmo learn check 3
```

마지막 항목은 실험을 실제로 돌려 A7을 뺐을 때 발견 사항이 줄어드는지 확인합니다.
