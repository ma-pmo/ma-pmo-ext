# 실습 6 — 승인 게이트 보정하기

**[English](README.md) | 한국어** · 강의: [08 에이전트 운영하기](https://github.com/ma-pmo/ma-pmo-ext/blob/main/docs/learn/08-operating-agents.ko.md)

승인 게이트는 확신도가 낮은 메시지를 사람에게 보냅니다. 에이전트의 확신도가 의미 있을 때만 안전장치가
됩니다. 이번 실습에서는 그것을 측정하고, PMO가 정하듯 기준값을 고릅니다. 검토할 시간은 한정돼 있고,
빠져나가는 오류는 최대한 적어야 합니다.

**익히는 것:** Brier 점수, 기대 보정 오차(ECE), 지표를 한도 안의 운영 결정으로 바꾸기.

## 파일

- `calibrate.py` — `brier(pairs)`, `ece(pairs, bins=10)`, `choose_threshold(pairs, max_review)`.
  각 쌍은 `(확신도, 맞았는지)`입니다.

## 단계

1. **Brier 점수** — `(확신도 − 결과)²`의 평균. 맞으면 결과 1, 틀리면 0.
2. **ECE** — 확신도를 10개 구간으로 나눕니다(마지막 구간은 1.0 포함). 비어 있지 않은 구간마다
   *표본 비율 × |정확도 − 평균 확신도|*를 더합니다. 0.8이라고 말하고 80% 맞히면 0이 됩니다.
3. **기준값** — `확신도 < 기준값`이면 사람에게 갑니다. `확신도 ≥ 기준값`인 틀린 결과는 빠져나갑니다.
   검토 건수가 `max_review` 이하인 후보 중 빠져나가는 오류가 가장 적은 것을 돌려줍니다(같으면 더 낮은
   기준값). 맞는 후보가 없으면 `ValueError`를 냅니다.
4. 데모 데이터에서 `ma-pmo eval` → `[calibration]`과 비교해 보세요(먼저 A4가 포함된 시나리오 실행).

## 채점

```bash
ma-pmo learn check 6
```
